各位老师，大家好。今天这节课，我们一起来学习竞品分析。为什么新人必须学这块内容。咱们日常的工作场景里，不管是首次和家长沟通咨询，还是后期进入续报阶段，竞品对比类问题是高频异议。很多家长之前已经带孩子体验过别家少儿编程课，或者正在多家机构之间做选择，很容易直接问：核桃编程和别的机构比，差别在哪？刚上手的时候，一听到这类问题很容易慌：要么不知道怎么回答，下意识去贬低对手；要么讲不出咱们产品独有的亮点，只能笼统说我们更好，家长听完没有感知，信任很难建立。所以我们学习竞品分析，核心目标不是去背一堆竞品的缺点，更不是主动去踩其他机构。而是先熟悉市面上同类产品的特点，当家长主动提起对比的时候，我们可以做到客观、理性地拆解差异，站在孩子学习需求的角度，帮家长理清不同课程的适配人群，顺理成章讲清楚核桃编程的优势，打消家长的顾虑。只有我们自己吃透竞品、吃透自家产品，面对家长的对比提问，回答才稳、才有说服力。

P04 · 阶段1·开篇与竞品需知 · 成交三性：重要性·紧迫性·唯一性——唯一性是竞品分析的重点 · 166 秒
我们今天进入竞品须知板块，核心就是成交三性：重要性、紧迫性、唯一性，也是我们跟家长沟通时最核心的一套逻辑。首先第一个，重要性：为什么要学少儿编程？我们要先给家长讲明白少儿编程本身的价值。编程不是单纯教孩子敲代码，核心是锻炼孩子的逻辑思维、拆解问题、试错思考的能力，同时对接信息时代的素养，还有 CTL、GESP 这类权威赛事、科技特长生的升学规划路径，这是编程这件事本身的价值，先让家长认可 “学编程这件事是有意义的”。第二个，紧迫性：为什么现在就要学？认可价值之后，我们要告诉家长不能一直观望、拖延。孩子的思维黄金窗口期是有限的，低龄阶段更容易建立思维习惯；而且赛事、升学规划都有对应的时间节点，越往后，孩子课业压力越来越大，时间会越来越紧张，起步晚了，准备周期就不够。所以不是以后学不学，而是要抓住当下合适的阶段开始。前面这两点，是所有编程机构都能讲的，竞品一样会跟家长说。那我们真正拉开差距、打动家长、促成选择的，就是第三点，也是今天的重点 ——唯一性：为什么选择核桃编程？别的机构能讲编程的好处、能说要趁早学，但核桃有我们独有的优势。我们深耕少儿在线编程多年，有完整从 Scratch 到 C++ 的进阶体系，配套标准化实操课程、赛事辅导、专业的教研和服务，主打重实操，不是单纯看动画、背概念；同时我们的课程体系、学情跟进、赛考规划是成熟闭环，是专门适配孩子长期编程成长的。简单说：很多地方都能学编程，但核桃是更专业、体系更完整、更适合孩子稳步走竞赛和素养路线的选择，这就是我们的不可替代性。总结一下三性的逻辑：先靠重要性解决家长 “要不要学” 的疑问，再用紧迫性打消家长 “以后再说” 的拖延心态，最后用我们核桃独有的唯一性，回答家长 “凭什么选我们，而不是别家”，这也是我们课导在和家长沟通时，贯穿全程的底层思路。来看一道题，竞品需知板块，重点讲的是成交三性中的哪一性？

P09 · 阶段3·常见竞品对比 · 六维对比表：猿封装代码·编程猫 Kitten 自创·西瓜 C++ 外包·核桃 S/P/C 全自研 · 399 秒
接下来我们结合这张对比表，从 6 个维度，帮大家客观看看市面上主流编程机构的区别，方便咱们结合孩子目标做选择。首先第一块，我们先看机构背景和起家根基。先看成立时间：编程猫 2015 年成立，是这几家里面最早的，本身也是编程起家；核桃编程 2017 年成立，同样从创立之初就专注少儿编程赛道，是原生做编程的机构。很多家长听过猿辅导，名气很大，这个我们完全认可。但大家要区分一点：猿辅导本身是学科类起家，编程只是它拓展出来的一个分支业务，不是核心主业。而且猿辅导 Python 是封装代码，简单说就是把底层代码提前封装好了，孩子只是调用模块，学的内容和竞赛要考察的原生代码不一样。一旦离开它这个学习平台，孩子很难独立写出完整程序。再看编程猫，虽然起步早，但是它主推 Kitten 自研语言，这个语言属于平台自创，并不是行业通用编程语言，没办法对接 GESP、CSP 这类主流信息学赛事，后续孩子想打竞赛、走科技特长路线，这套语言是用不上的。西瓜创客这边，它的 C++ 课程是外包团队承接的，课程研发不是自有团队把控，整套 C++ 体系的稳定性、连贯性会弱一些。线下机构的特点是软硬件穿插学习，今天接触乐高硬件、明天学一点软件编程，内容比较零散，没有循序渐进、长期连贯的进阶学习路线。而核桃编程，Scratch 图形化、Python、C++ 全部都是自研体系，一条路线贯通，专门对标信息学学习路径。第二点，整套课程体系核桃是真正一站式闭环：Scratch→Python→C++，从低龄启蒙，到后期冲刺竞赛、科技特长生，一条路线可以一直学下去，规划清晰。其他机构都有明显短板：要么编程语言不通用，要么高阶 C++ 外包、要么硬件软件穿插打乱节奏，很难支撑孩子从启蒙到竞赛的完整长期规划。第三点，我们来看学习周期，也就是孩子要花多久学完。大家看表格里核桃的节奏：Scratch 1 年，Python 1 年，C++ 3 年，整体节奏规划紧凑合理，每一个阶段目标明确。对比竞品：猿、编程猫、西瓜，整体学习周期都比核桃更长。线下机构耗时是最久的，很多孩子光 Scratch+Python 就要学 6 年左右，周期拉得很长，等到想往 C++ 进阶的时候，时间非常紧张，甚至很多线下班根本不开稳定的 C++ 竞赛班，孩子很难走到竞赛阶段，时间成本很高。第四块，费用和退费风险，我们折算成单节课来看会更直观。核桃折算下来单节课只要 60 多块。猿辅导单节课折算 80 多，而且是按阶段缴费，长期下来成本更高。编程猫表面看报价低，但刚刚咱们提到，它的 Kitten 语言不通用，没法对接竞赛，看着便宜，但是匹配不了咱们走特长、打比赛的目标，性价比就要打折扣。线下机构单节价格普遍 200-300 元，单价高出非常多。同时线下退费协议里一般都设置了退费违约金。大家可以联想一下线下的健身、舞蹈兴趣班，一旦中途想退费，流程麻烦、限制多，还会有门店经营、闭店的风险，资金风险比线上更大。第五点上课模式核桃是实操课。很多家长可能会好奇，什么是实操课？简单说，上课全程孩子自己动手敲代码、调试程序，老师全程在线实时监测每个孩子的屏幕、学习状态，孩子卡壳、写错代码的时候，老师能够及时发现、针对性引导，孩子是边做边学。猿辅导是大班直播课，一个班孩子很多，老师要跟着全班进度走。如果咱们家孩子一个地方卡住了，老师很难单独停下来，专门等孩子、单独讲解，跟不上就容易掉队。编程猫、西瓜创客是 AI 双师模式，AI 录播为主，非常考验孩子自觉性。孩子听懂与否、有没有理解，老师没法实时看到，有问题必须孩子主动提问才能得到解答，被动的孩子很容易积攒问题。线下虽然是面对面授课，但少儿编程专业师资比较稀缺，老师水平参差不齐，师资稳定性很难保证。第六点，也是很多家长最关心的：赛考、考级，也就是升学含金量核桃这边，对接 CTL、GESP 这类认可度高、官方主流的考级，同时也有白名单国家级赛事资源，证书是信息学圈认可的，能够对接科技特长生规划。猿辅导、西瓜创客主推自家自研考级，这类证书属于机构内部认证，外面认可度低，后续升学、报名校测的时候很难被认可。编程猫和线下机构的赛考配套比较零散，没有完整的考级 + 赛事晋升路线，很难支撑孩子长期竞赛规划。最后总结一下：不是说别的机构不好，每家定位不一样。如果咱们只是想让孩子简单体验、玩一玩，选择会很多；但如果咱们目标很明确，想走信息学、科技特长生，需要一套连贯、通用、对接正规赛事，从启蒙一直学到 C++ 竞赛的体系，核桃这套一站式方案会更适配咱们孩子。来看一道题，猿编程 Python 的核心问题是什么？

P11 · 阶段4·线上竞品对比 · 线上对比三抓手：比模式·比成绩·比价格（比价=算单课时+绑价值） · 142 秒
